# Online Billboard Booking System Frontend

This is a React + Vite frontend for the Online Billboard Booking System. It features a dynamic map for selecting billboards by location and connects to a Spring Boot backend via REST APIs.

## Features
- Modern, user-friendly UI
- Dynamic map for billboard selection (Leaflet/Google Maps)
- REST API integration with backend

## Getting Started
1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```
